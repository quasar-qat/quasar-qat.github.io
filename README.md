# quasar-qat.github.io

Project page for **QUASAR: Lowering the Loss Floor of Quantization-Aware Training with Loss-Aware Reconstruction**
([arXiv 2608.13966](https://arxiv.org/abs/2608.13966)).

Static site with no build step: `index.html` plus `assets/` (CSS, vanilla JS, JSON data, the hero MP4).
Fonts come from Google Fonts; everything else is self-contained.

## Preview locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000 (a server is needed because the charts `fetch()` their JSON data).

## Deploy (GitHub Pages)

The site is served from the repository `quasar-qat/quasar-qat.github.io`:
Settings → Pages → Build and deployment → Source: *GitHub Actions*.
The workflow `.github/workflows/pages.yml` publishes everything except `tools/`, `README.md`, `.github/` and `.gitignore`.

Fallback: *Deploy from a branch* → `main` / `/ (root)`. This serves the whole repository, `tools/` included;
`.nojekyll` disables Jekyll so every file is served as is.

## Launch checklist

- Source: arXiv v2 (data, captions). No figure/table numbers shown. Announce v2 before sharing.
- Search, Scholar and LLM-assistant discoverability (deploy, Search Console, Bing/IndexNow, Brave, Hugging Face, awesome lists, Zenodo, author profiles): follow `tools/_private/LAUNCH_SEO.md` in order. It is a local file (git-ignored, never pushed).

## Layout

| Path | What |
|---|---|
| `index.html` | the page |
| `404.html` | not-found page |
| `index.md`, `llms.txt` | Markdown copies of the page for LLM fetchers (generated by `tools/seo/build_llms.py`) |
| `quasar.pdf` | PDF of the paper (arXiv v2) on the site's own host (target of `citation_pdf_url`) |
| `quasar.bib` | BibTeX entry |
| `sitemap.xml`, `robots.txt` | crawler files (`robots.txt` disallows `/tools/`) |
| `<32 hex>.txt` | IndexNow key file (its body is the key; used by `tools/seo/indexnow.sh`) |
| `.github/workflows/pages.yml` | GitHub Pages deploy workflow |
| `assets/css/` | `site.css` (design system), `widget.css`, `charts.css`, `results.css` |
| `assets/js/` | `viz.js` (shared SVG chart helpers), `quasar-core.js` (QUASAR / Standard QAT reconstruction of one weight group, bit-exact port of the paper's Algorithm 1), `fig-loop.js` (Fig. 2 diagram), `widget-group.js`, `charts-curves.js`, `charts-results.js`, `site.js` |
| `assets/data/` | numbers and curves, extracted from the arXiv v2 LaTeX source and the paper's figure data |
| `assets/img/` | favicons, `og.png` and `og-*.jpg` (share-card and structured-data images), figure images |
| `assets/video/` | hero animation (H.264) and posters |
| `tools/` | generators and checks (not needed to serve the page) |

## Tools

- `tools/paper_text.py` → `tools/paper_plain.txt`: plain text of the arXiv v2 source.
- `tools/check_page_text.py index.html`: every prose sentence on the page must be verbatim from the paper.
- `tools/build_results.py`, `tools/extract_curves.py`, `tools/export_groups.py`: regenerate `assets/data/`.
- `tools/run_quasar_parity.sh`: checks `quasar-core.js` against the numpy reference of Algorithm 1.
- `tools/video/`: generator for the hero animation and icons (need `QUASAR_ANIM_DIR`, see `tools/README.md`).
- `tools/seo/build_static_tables.py`: bakes the static screen-reader data tables (full chart data from `assets/data/`) into `index.html`, so crawlers that do not run JavaScript see every method and number.
- `tools/seo/build_llms.py` → `llms.txt`, `index.md`: Markdown copies of the page for LLM fetchers.
- `tools/seo/indexnow.sh` (after launch only; `-n` = dry run): pings IndexNow for `/` and `/quasar.pdf` with the key file at the repo root.

See `tools/README.md` for the inputs each script expects.
